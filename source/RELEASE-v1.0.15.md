# Super Earth Arsenal Mod Pack v1.0.15

This release adds the **AC-8 Autocannon Backpackless Rework** as the eighteenth mod. The other seventeen mods keep their v1.0.14 gameplay changes.

## AC-8 changes

- The Autocannon call-in delivers only the weapon, leaving the backpack slot free. It can reload itself without the Automatic Cannon Backpack.
- Ammunition is **10 loaded rounds plus 60 reserve rounds**. The familiar five-round top-clip reload remains, now usable while walking with a matching walking animation. Reloading is about **20% faster**.
- A resupply is set to restore up to **60 reserve rounds**. A pickup cannot exceed the weapon's reserve capacity.
- **APHET:** direct damage rises from 325 normal / 260 durable to **375 normal / 340 durable**; direct armor penetration rises from AP4 to **AP5**; impact explosion normal damage rises from 150 to **180**.
- **FLAK:** explosion normal damage rises from 190 to **210** and outer blast radius from 7 to **8 metres**. The parent projectile remains 150 normal / 150 durable, and shrapnel remains unchanged.
- **Shared explosion:** JAR-5 Dominator **High Explosive ammunition** uses the same explosion as AC-8 FLAK, so it also receives the 210-normal-damage explosion and 8 m outer radius. Other JAR-5 ammunition is outside this change.

## Install and test status

Install this modpack **or** the individual mods, never both. Requires the supported Helldivers 2 Steam build 25480438 and Bingus Shared Loader v19. Import the ZIP into Arsenal, enable its option, Purge and Deploy, and restart. Follow the existing Punisher Plasma equipment precautions in the repository README when replacing the modpack.

The user confirmed backpackless AC-8 self-reload and the corrected walking animation in game. The v0.1e test modpack passed a fresh launch with **55 loaded, 0 failed**, AC-8 Applied, and the 60-round refill setting loaded. This release ZIP contains the same gameplay resources. The release ZIP itself and every weapon combination have not been separately gameplay-tested. APHET/FLAK damage outcomes, external-backpack team reload, and multiplayer behavior remain to be checked.
