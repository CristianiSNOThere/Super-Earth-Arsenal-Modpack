# Super Earth Arsenal Mod Pack v1.0.16

This update adjusts AC-8 Autocannon handling in the 18-mod pack. The other seventeen mods retain their v1.0.15 gameplay changes.

## AC-8 Autocannon

- Ergonomics increases from **17 to 30**, making the Autocannon easier to bring onto target.
- Horizontal and vertical recoil drift decrease from **200 / 450 to 150 / 337.5**. Horizontal and vertical recoil climb decrease from **2 / 100 to 1.5 / 75**. Each recoil value is **25% lower** than stock.
- The call-in still delivers only the gun, leaving the backpack slot free. It carries **10 loaded plus 60 reserve rounds** and self-reloads in the familiar five-round top clips while walking, about **20% faster** than stock. A resupply can restore up to **60 reserve rounds**.
- **APHET** remains at **375 normal / 340 durable direct damage**, **AP5** direct armor penetration, and **180 normal impact explosion damage**.
- **FLAK** retains its **210 normal explosion damage** and **8 m outer blast radius**. Its parent projectile and shrapnel are unchanged.
- **Shared effect:** JAR-5 Dominator **High Explosive ammunition** uses the same explosion as AC-8 FLAK and receives that explosion damage/radius increase. Other JAR-5 ammunition is outside this change.

## Install

Install this modpack **or** the individual mods, never both. Requires the supported Helldivers 2 Steam build 25480438 and Bingus Shared Loader v19. Import the ZIP into Arsenal, enable its option, Purge and Deploy, then restart. Follow the Punisher Plasma equipment precautions in the repository README when replacing the pack.
